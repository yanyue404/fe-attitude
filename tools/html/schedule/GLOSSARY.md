# 排班

为同一个人把班次铺到公历日上，用来看清一段连续月份里每天是什么班。

## Language（语言）

**班次**：
贴在某一个公历日上的名称，由使用者自己录入，并带有一种颜色。同一份名单里名称不重复。休息也是班次。一个班次不含上下班钟点。班次改名后，凡是用到它的地方都显示新名字。
_Avoid_：工作种类、班种、任务

**循环**：
有序的班次序列。每个位置对应连续的一天，末尾之后回到第一个位置。同一种班次可以占据相邻的多个位置。经过月界时不从月初重来。
_Avoid_：周期、轮班模板、规律

**排班区间**：
一次要看的时间，由一个或多个连续的完整公历月组成，至少一个月。
_Avoid_：日期范围、档期

**锚点日**：
循环第一个位置所对应的那一个公历日。全表只用这一个日子对齐。
_Avoid_：起始日、开始日期

**月历**：
某一个公历月的格子图。一格一天，周一为第一列。该月的格子写着那一天的班次名称，并以班次颜色铺底。
_Avoid_：周表、清单
